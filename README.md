# Mavenproject1

Projeto simples em Java (Maven) que demonstra a leitura de dados via teclado
com a classe `Scanner`.

## Descrição

O programa solicita ao usuário, pelo console, as seguintes informações:

- Nome
- Idade
- Curso

Os dados são armazenados em variáveis do tipo `String` para uso posterior.

## Tecnologias

- Java
- Maven
- Classe `java.util.Scanner`

## Como executar

1. Clone o repositório:
```bash
   git clone https://github.com/seu-usuario/Mavenproject1.git
```
2. Acesse a pasta do projeto:
```bash
   cd Mavenproject1
```
3. Compile e execute:
```bash
   mvn compile exec:java -Dexec.mainClass="Mavenproject1"
```
